# 黑白球大冒險 — 雙人同畫面合作 2D 平台遊戲

本機雙人、同一台電腦、同一個畫面、同一個關卡,兩名玩家全程同時存在:
可同時移動、跳躍、攻擊與取得道具。不使用回合制、不使用輪流操作。

正式版：https://game222-20b66.web.app

## 地圖難度

- 簡單、專家、困難、無盡四種模式，每種模式各有 10 關可選。
- 難度會改變浮台、尖刺與窄橋，也會提高小怪數量和幽靈箱生成率。
- 無盡模式採類似離線小恐龍的自動前進玩法：沒有終點，地圖會持續生成，並隨距離提升跑速、障礙、小怪與幽靈節奏；每 100 公尺更新重生檢查點，單人與雙人最佳距離分開保存。

## 排位模式

- 單人與多人排位積分分開保存在瀏覽器。
- 段位由青銅、白銀、黃金、鑽石到王牌；每階 4 顆星，每顆星 500 積分。
- 多人勝利分由生命 50%、擊殺 30%、時間 20% 組成，基礎分每回合最高 150，MVP 額外 +10。
- 單人排位使用原本的關卡結算總分，單人壓力板關卡會自動套用單人開門規則。

## 執行方式

在專案根目錄啟動靜態伺服器（需要安裝 Python 3）：

```bash
python -m http.server 8642
```

然後在瀏覽器開啟 `http://localhost:8642`。專案包含 Firebase 的 ES module，
因此建議透過靜態伺服器執行，不要直接以 `file://` 開啟 `index.html`。

## 操作方式

準備畫面可讓 P1、P2 各自從 10 名角色中切換造型；選擇會保存在瀏覽器，且不改變角色的
碰撞體積、移動速度或能力數值。可選角色：千層蛋糕、狗狗、金元素、青龍、珍珠奶茶、
閃電、蛇蛇、鈴鐺、養樂多、魔。

| 動作 | P1 | P2 |
|---|---|---|
| 左/右移動 | A / D | ← / → |
| 跳躍 | W | ↑ |
| 空中快速下降 | S | ↓ |
| 使用火焰/冰雪能力 | F | 右Ctrl 或 數字鍵0 |
| 互動(救援隊友) | E | 右Shift |

共用鍵:`Esc` 暫停、`R` 重新開始目前關卡。

### 控制器

支援標準手把(Gamepad API):左搖桿/十字鍵移動、南側按鈕(A/×)跳躍、
西側按鈕(X/□)使用能力、東側按鈕(B/○)互動、Start 暫停。
第一支接上的手把為「控制器 1」、第二支為「控制器 2」。
在「角色與控制設定」中可以自由把任一玩家配到鍵盤左側、鍵盤右側、控制器 1 或控制器 2;
兩名玩家不可能共用同一裝置(選同一個會自動交換),因此輸入絕不互相干擾。
只接一支手把時,可設定成一人鍵盤、一人手把。

## 系統規格摘要

- **生命**:每人每關 5 條,完全分開計算;一人死亡不影響另一人。
  兩人生命皆歸零才 Game Over。設定中可切換「每關恢復 / 延續到下一關」。
- **死亡流程**:停輸入 → 死亡效果 → 扣 1 命 → 1.5 秒 → 安全位置重生 → 2 秒保護,
  並清除該玩家的火焰/冰雪/馬鈴薯/無敵狀態(不重置隊友)。
- **合作復活**:一人淘汰後留下靈魂標記;隊友(至少 2 條命)在安全區域靠近長按互動鍵
  2 秒 → 扣自己 1 條命、隊友以 1 條命+3 秒無敵在身旁重生(+300 分)。
  鬼魂事件中、危險區域、剩 1 命時不可救援;救援中受傷會中斷。
- **受傷規則**(每人獨立):無敵→不受傷;馬鈴薯/火焰/冰雪→失去狀態不扣命;一般→死亡。
  兩名玩家彼此不碰撞、不互相傷害。
- **道具**:道具格一次性,原子式 `tryCollect`,最先碰到的玩家取得,只影響取得者。
  火焰/冰晶投射物記錄 `ownerPlayerId`,不會傷害任何玩家,每人上限各 3 顆。
- **鬼魂事件**:任一人觸發、影響兩人。每次隨機出現金／紫／黑其中一種，警告後有
  3 秒逃跑時間(兩人 +40% 速度)。金色沿用原設定(8 秒、速度 6.6)；紫色追逐 30 秒、
  速度 8.4，且每 5 秒所有分身各分裂一次；黑色追逐 40 秒、速度 9.2，為最快階級。
  鬼魂穿牆、不可消滅;每秒依各分身位置重選最近存活目標(平滑轉向);
  碰到誰只扣誰的命;事件中死亡者待事件結束才重生;
  存活者 +500(逃脫次數+1)、被抓者 +100;通關/重新開始立即取消。
- **鏡頭**:單一鏡頭跟隨兩名存活玩家中點,依距離在 orthographic size 5~8 間平滑縮放
  (開始縮放距離 7、最大允許距離 14),永不超出關卡邊界;
  一人在終點等待時只跟隨仍在路上的玩家。
- **距離限制**:>12 顯示邊緣方向箭頭與「等待隊友」,領先者逐漸減速;
  =14 領先者無法再拉開;≥13 持續 3 秒 → 落後者傳送到領先者附近安全位置
  (不扣命、1 秒保護,不會傳到尖刺/炸彈/敵人/坑洞/鬼魂/終點觸發器)。
- **重生優先序**:啟用的檢查點 → 存活隊友附近安全點(距離 ≥1.5,地面偵測) → 關卡起點。
  隊友在危險區時改用檢查點。
- **終點**:預設「所有未淘汰玩家都須抵達」;先到者進入安全等待狀態(不受傷、不能離開、
  顯示等待隊友);隊友已淘汰則一人抵達即過關。終點區為安全區。
- **分數**:個人分(洋蔥 100 / 冰凍擊碎 150 / 道具 50 / 鬼魂存活 500 / 救援 300)
  + 團隊分(合計 + 過關 1000 + 無人死亡 500 + 同步抵達 300 + 時間獎勵)。
- **雙人機關**:雙人壓力板門 — 兩塊板同時踩下才開門,離開 1 秒後關閉、
  不會夾死玩家;一人淘汰時自動切換單人模式(一塊板即可)。
- **暫停**:任一人按 Esc;所有玩家/敵人/炸彈/鬼魂倒數/投射物停止,UI 可操作。

## 程式架構(對應規格類別)

| 檔案 | 內容 |
|---|---|
| `js/input.js` | `PlayerId`、`PlayerInputRouter`(裝置→玩家 InputFrame,雙鍵盤配置+雙手把) |
| `js/levels.js` | `LevelBuilder` + 10 個關卡定義(LevelConfig) |
| `js/level.js` | `RuntimeLevel`(圖塊/門/檢查點/終點區)、AABB 碰撞、`findSafeSpot` |
| `js/entities.js` | `ItemBox`(原子式收集)、`DroppedItem`、`Projectile`、`Onion`、`Bomb` |
| `js/ghost.js` | `GhostEventController`(雙人目標選擇/階段/獎勵) |
| `js/player.js` | `PlayerController`(每位玩家獨立實例,無全域單例狀態) |
| `js/systems.js` | `PlayerManager`(登錄/重生)、`MultiplayerCameraController`、`PlayerDistanceController`、`ReviveController`、`TeamGoalController`、`TeamScoreManager` |
| `js/ui.js` | `MultiplayerHUDController`(P1 左上/P2 右上/中上團隊資訊、邊緣箭頭、選單) |
| `js/game.js` | `GameWorld`(關卡世界)、`Game`(狀態機) |
| `js/main.js` | 固定時間步長迴圈(分頁隱藏時以計時器後備) |

## 未來線上雙人模式的預留設計

- 遊戲邏輯只讀 `InputFrame`(每 tick、每位玩家一份),不直接讀裝置;
  線上模式只需把遠端玩家的 InputFrame 由網路餵入 `PlayerInputRouter`。
- 所有玩家系統以 `PlayerId` 索引,`players` 為陣列,無單例;擴充為 N 人成本低。
- 固定時間步長(60Hz)更新,便於未來做確定性同步或快照插值。
- 需要再調整的部分:亂數(目前粒子用 `Math.random`,需改種子亂數)、
  事件廣播(鬼魂觸發/道具收集需改為授權端裁決)、延遲補償、大廳/配對 UI。
